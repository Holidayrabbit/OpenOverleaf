\section{Tools on the desk}

The assistant can list the project, read a file, write a file, run a
short shell command, and compile this document. A good turn is small:
read the section, change one idea, compile, and quote the log if the
build fails.

\begin{itemize}
  \item Entry file: \texttt{main.tex}
  \item Sections: \texttt{sections/intro.tex}, \texttt{sections/method.tex}
  \item Preview: \texttt{build/main.pdf}
\end{itemize}
