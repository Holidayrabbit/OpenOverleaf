\section{A local studio}

This project lives in a folder on your machine. The editor saves that
folder, the compiler reads it, and the terminal starts there. Nothing in
the sample is fetched from a hosted \LaTeX\ service.

OpenOverleaf is a single-user studio. Saving a file, compiling
\texttt{main.tex}, and reading the log are the whole loop. Real-time
collaboration is deliberately out of scope for this version.

The agent panel can edit the same files. It is most useful when a
model key is configured. Without one, the editor, the preview, and the
terminal still run.
